## ภาพรวม

Tuty Shop เป็นร้านขายเสื้อผ้าออนไลน์ แบ่งเป็น 3 ส่วน คือหน้าร้านสำหรับลูกค้า
หน้า Admin Dashboard และ REST API ที่ทั้งสองส่วนใช้ร่วมกัน

## สิ่งที่ทำ

- REST API ด้วย Express สำหรับสินค้า ผู้ใช้ และคำสั่งซื้อ เก็บข้อมูลใน MongoDB ผ่าน Mongoose
- ระบบสมัครสมาชิกและเข้าสู่ระบบ เข้ารหัสรหัสผ่านด้วย bcrypt และป้องกัน route ด้วย JWT
- ตรวจสอบข้อมูลที่ส่งเข้ามาด้วย express-validator และเพิ่ม security header ด้วย Helmet
- หน้า Admin สำหรับจัดการสินค้าและผู้ใช้
- หน้าร้านพัฒนาด้วย HTML, CSS และ JavaScript
