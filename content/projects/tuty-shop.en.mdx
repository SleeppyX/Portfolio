## Overview

Tuty Shop is a clothing store with three parts: a storefront for customers,
an admin dashboard, and a REST API that both of them use.

## What I built

- REST API in Express for products, users, and orders, with data stored in MongoDB through Mongoose
- Sign-up and login with passwords hashed by bcrypt and JWT-protected routes
- Input validation with express-validator and security headers with Helmet
- Admin pages for managing products and users
- Storefront pages built with HTML, CSS, and JavaScript
