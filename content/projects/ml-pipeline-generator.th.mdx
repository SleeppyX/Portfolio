## ภาพรวม

ผู้ใช้อัปโหลด dataset แล้วแอปจะพาทำ machine learning pipeline ครบทุกขั้น
ตั้งแต่ทำความสะอาดข้อมูลไปจนถึงเทรนและเปรียบเทียบโมเดล โดยมี reasoning engine แบบ rule-based
แนะนำตัวเลือกในแต่ละขั้นพร้อมอธิบายเหตุผล คนที่ไม่มีพื้นฐาน ML ก็เข้าใจได้ว่าโมเดลสุดท้ายถูกสร้างมาอย่างไร

เป็นโปรเจกต์จบ (senior project) สาขาวิศวกรรมคอมพิวเตอร์และปัญญาประดิษฐ์ ที่ PIM
ผมกับเพื่อนออกแบบและพัฒนาทั้งโปรเจกต์ร่วมกัน

## 1. Data Preparation

- **อัปโหลด:** รองรับไฟล์ CSV, XLSX, XLS และ JSON แสดงตัวอย่างข้อมูลและให้เลือกคอลัมน์เป้าหมาย
- **ทำความสะอาดข้อมูล:** ทำ data profiling แล้วลบคอลัมน์ ลบแถวซ้ำ จัดการ missing value และ outlier
- **สำรวจข้อมูล (EDA):** ดูการกระจายตัวของข้อมูล ความสัมพันธ์ระหว่าง feature กับเป้าหมาย และ correlation
- **แปลงข้อมูล:** encoding (one-hot, label, ordinal), scaling (log, standard, min-max, robust)
  และเลือก feature พร้อมคำแนะนำว่าควรตัดตัวไหน

## 2. Model Process

- **แบ่งข้อมูล:** training set 80% และ test set 20%
- **แข่งขันโมเดล:** เทรนโมเดลหลายตัวทั้งงาน classification และ regression เช่น random forest,
  logistic regression, SVM, kNN, gradient boosting, XGBoost, LightGBM และ CatBoost
  พร้อมจูน hyperparameter
- **วัดผล:** มี leaderboard จาก training set แล้ววัดผลบน test set ด้วย accuracy, precision,
  recall, F1 สำหรับ classification หรือ MSE, RMSE, R² สำหรับ regression และมี confusion matrix

## 3. Insight

- **Feature importance:** ใช้ permutation importance และแสดง 3 feature ที่สำคัญที่สุด
- **Data visualization:** กราฟรายคอลัมน์และ correlation heat map
- **Model guide:** จุดแข็ง จุดอ่อน และคะแนนประเมินของโมเดลที่เลือก
- **Pipeline trace:** บันทึกทีละขั้นตั้งแต่อัปโหลด ทำความสะอาด แปลงข้อมูล ไปจนถึงสร้างโมเดล
  พร้อมคำอธิบายการตัดสินใจในแต่ละขั้น
