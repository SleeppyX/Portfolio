## ภาพรวม

E-CMIS เป็น prototype ฝั่ง front-end ของระบบบริหารจัดการคดีที่พัฒนาระหว่างฝึกงานตำแหน่ง Software Developer
ครอบคลุมขั้นตอนหนึ่งของกระบวนการ ได้แก่ การพิจารณาเรื่อง การส่งเรื่องเพื่ออนุมัติ และการบรรจุเรื่องเข้าวาระการประชุมคณะกรรมการ
ไม่ระบุชื่อหน่วยงาน และภาพหน้าจอได้ปิดข้อมูลที่ระบุตัวตนแล้ว

## สิ่งที่ทำ

- หน้าจอกว่า 30 หน้า แยกตามบทบาทผู้ใช้ แต่ละบทบาทมีกล่องงานและสิทธิ์ของตัวเอง
- ขั้นตอนอนุมัติพร้อมติดตามสถานะ และแจ้งเตือนเมื่อใกล้ครบกำหนด (SLA)
- ระบบสร้างเอกสารจากเทมเพลต Word และส่งออกรายงานเป็น Word, Excel และ PDF
- Dashboard สถิติพร้อมกราฟและตารางรายงานรายเดือน
- เชื่อมต่อ Supabase ได้ และมีข้อมูลจำลองสำรองไว้ให้ demo ทำงานได้แม้ไม่มีฐานข้อมูล

## เทคโนโลยี

HTML, CSS และ JavaScript ล้วน ใช้ Supabase เก็บข้อมูล
