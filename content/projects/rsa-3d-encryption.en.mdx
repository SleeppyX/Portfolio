## Overview

A small security project that protects 3D model files. RSA alone can only encrypt
a few hundred bytes, so the scripts use hybrid encryption.

## How it works

1. Generate a 2048-bit RSA key pair
2. Encrypt the model with a random AES-256-GCM key, which also detects tampering
3. Encrypt that AES key with the RSA public key (OAEP padding with SHA-256)
4. Decrypt in reverse with the private key and get back an identical `.glb` file

Tested with the Stanford Bunny model.
