## ภาพรวม

Task Board ช่วยให้ทีมเล็กติดตามงานได้ โดยไม่ต้องใช้เครื่องมือจัดการโปรเจกต์ที่ซับซ้อน
_(ผลงานตัวอย่าง: ให้แทนที่ด้วยข้อมูลของคุณเอง)_

## สิ่งที่ทำ

- ออกแบบ UI ใน Figma แล้วพัฒนาด้วย Next.js และ Tailwind CSS
- ทำระบบลากวางที่ใช้คีย์บอร์ดได้ด้วย เพื่อการเข้าถึง (accessibility)
- พัฒนา REST API และออกแบบฐานข้อมูล PostgreSQL ด้วย Prisma

## ความท้าทาย

ทำให้ลำดับการ์ดถูกต้องเมื่อมีสองคนย้ายการ์ดพร้อมกัน
แก้ด้วยเทคนิค fractional indexing ทำให้การย้ายแต่ละครั้งแก้ข้อมูลแค่แถวเดียว

## ผลลัพธ์

- มี 3 ทีมใช้งานจริงระหว่างฝึกงาน
- คะแนน Lighthouse performance 98
